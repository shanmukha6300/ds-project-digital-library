It serves as an academic repository, laboratory protocol handbook, and continuous evaluation telemetry platform for students, faculty mentors, and evaluators.

## 🚀 Key Features

### 1. 🎓 Student Profile & Continuous Evaluation Dashboard
- Real-time telemetry showcasing academic scores, practical marks, and mentor verification.
- Dynamic profile photo management and academic metadata binding.

### 2. 🛠️ Data Science Tools & Frameworks Stack
Curated documentation and references for industry-standard tools:
- **Python 3.x**: Core scripting and numerical computing engine.
- **NumPy**: Multidimensional arrays, linear algebra, and vectorization.
- **Pandas**: High-performance DataFrame manipulation and time-series analysis.
- **Matplotlib & Seaborn**: Statistical visualizations, correlation heatmaps, and distributions.
- **Scikit-Learn**: Supervised/unsupervised machine learning pipelines and metrics.
- **Jupyter Lab & Notebook**: Interactive experiment development.
- **SciPy & Statsmodels**: Statistical hypothesis testing and optimization.

### 3. 📚 Curriculum Modules & Chapter Guides
- Structured semester syllabus broken into digestible study modules.
- Concepts, theoretical foundations, and reference links.

### 4. 🔬 Laboratory Experiment Protocols
- Comprehensive catalog of laboratory experiments with objectives, algorithms, and execution protocols.
- Interactive code view with step-by-step guidance.

### 5. 🌓 Dynamic Tri-Theme System
- **☀️ Gamma Light**: Clean editorial interface tailored for readability.
- **🌹 Gamma Dark Rose**: Sleek contrast dark mode.
- **🌌 Cyber Midnight**: Modern developer-centric night theme.

## 💻 Local Setup & Running

This project is built with vanilla HTML5, CSS3, and modern JavaScript with zero heavy dependencies required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shanmukha6300/ds-project-digital-library.git
   cd ds-project-digital-library
   ```

2. **Open in Browser:**
   - Double-click `index.html`, or
   - Use VS Code **Live Server**, or
   - Run a lightweight HTTP server:
     ```bash
     python -m http.server 8000
     ```
   - Visit `http://localhost:8000` in your web browser.
